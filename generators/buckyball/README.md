# BuckyBall



## ISA

BuckyBall加速器支持以下三条核心指令，用于数据移动和矩阵计算操作：

### MVIN - 数据移入指令 (Move In)

**功能**: 将数据从主内存加载到scratchpad内存

**func7**: `0000010`

**格式**: `bb_mvin rs1, rs2`

**操作数**:
- `rs1`: 主内存地址
- `rs2[addr_length-1:0]`: scratchpad地址
- `rs2[2*addr_length+9:addr_length]`: 迭代次数

**操作**: 将主内存地址`rs1`处的数据加载到scratchpad地址`rs2[addr_length-1:0]`，执行`rs2[2*addr_length+9:addr_length]`次迭代

rs1:
```
┌─────────────────────────────────────────────────────────────────┐
│                        mem_addr                                 │
│                    (addr_length bits)                           │
├─────────────────────────────────────────────────────────────────┤
│                    [addr_length-1:0]                            │
└─────────────────────────────────────────────────────────────────┘
```

rs2:
```
┌──────────────────────────────────┬──────────────────────────────────────────┐
│        iter                      │                sp_addr                   │
│     (10 bits)                    │            (addr_length bits)            │
├──────────────────────────────────┼──────────────────────────────────────────┤
│ [2*addr_length+9: addr_length]   │            [addr_length-1:0]             │
└──────────────────────────────────┴──────────────────────────────────────────┘
```

### MVOUT - 数据移出指令 (Move Out)

**功能**: 将数据从scratchpad内存存储到主内存

**func7**: `0000011`

**格式**: `bb_mvout rs1, rs2`

**操作数**:
- `rs1`: 主内存地址
- `rs2[addr_length-1:0]`: scratchpad地址  
- `rs2[2*addr_length+9:addr_length]`: 迭代次数

**操作**: 将scratchpad地址`rs2[addr_length-1:0]`处的数据存储到主内存地址`rs1`，执行`rs2[2*addr_length+9:addr_length]`次迭代

rs1:
```
┌─────────────────────────────────────────────────────────────────┐
│                        mem_addr                                 │
│                    (addr_length bits)                           │
├─────────────────────────────────────────────────────────────────┤
│                    [addr_length-1:0]                            │
└─────────────────────────────────────────────────────────────────┘
```

rs2:
```
┌──────────────────────────────────┬──────────────────────────────────────────┐
│        iter                      │                sp_addr                   │
│     (10 bits)                    │            (addr_length bits)            │
├──────────────────────────────────┼──────────────────────────────────────────┤
│ [2*addr_length+9: addr_length]   │            [addr_length-1:0]             │
└──────────────────────────────────┴──────────────────────────────────────────┘
```

### bb_matmul_warp16 - 乘法指令

**功能**: 执行16-way warp的矩阵乘法运算

**func7**: `0011111`

**格式**: `bb_matmul_warp16 rs1, rs2`

**操作数**:
- `rs1[2*addr_length+9:2*addr_length]`: 迭代次数
- `rs1[2*addr_length-1:addr_length]`: 第二个操作数的scratchpad地址
- `rs1[addr_length-1:0]`: 第一个操作数的scratchpad地址
- `rs2[addr_length-1:0]`: 结果写回的scratchpad地址

**操作**: 从scratchpad读取两个操作数，执行矩阵乘法运算，并将结果写回到指定的scratchpad地址

rs1:
```
┌──────────────────────────┬───────────────────────────────┬──────────────────────────────┐
│         iter             │          op2_spaddr           │          op1_spaddr          │
│       (10 bits)          │      (addr_length bits)       │      (addr_length bits)      │
├──────────────────────────┼───────────────────────────────┼──────────────────────────────┤
│[2*addr_len+9:2*addr_len] │ [2*addr_length-1:addr_length] │ [addr_length-1:0]            │
└──────────────────────────┴───────────────────────────────┴──────────────────────────────┘
```

rs2:
```
┌─────────────────────────────────────────────────────────────────┐
│                      wr_spaddr                                  │
│                    (addr_length bits)                           │
├─────────────────────────────────────────────────────────────────┤
│                    [addr_length-1:0]                            │
└─────────────────────────────────────────────────────────────────┘
```
